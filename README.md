
# Secure Network Lab

## Overview
A practical networking and security project using Cisco Packet Tracer to explore network segmentation, routing, switching, and troubleshooting.

## Objectives
- Design a small-business network topology.
- Configure VLANs and inter-VLAN routing.
- Investigate trunk links and STP/RSTP behaviour.
- Apply appropriate network security controls.
- Test connectivity and document troubleshooting results.

## Tools
- Cisco Packet Tracer
- GitHub for documentation and version control
